# Отчёт о тестировании проекта MCHPY

## 1. Общая информация

**Проект:** MCHPY  
**Тип тестирования:** Ручное функциональное тестирование  
**Цель:** Проверка корректности работы конвертера величин, обработки пользовательского ввода и работы с пользовательскими единицами измерения.

## 2. Первоначальное тестирование

1)Позитивное тестирование

Проверка корректной работы программы при вводе допустимых значений.

| №    | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|------|---|---|---|---|
| P-01 | Конвертация 1000 м в км | 1 км | 1 км | Пройден |
| P-02 | Конвертация 0 °C в °F | 32 °F | -459,67 °F | Не пройден |
| P-03 | Конвертация 1 USD в EUR | Корректное значение по курсу | 0,893269 EUR | Пройден |
| P-04 | Конвертация 0 м в км | 0 км | 0 км | Пройден |
| P-05 | Конвертация -1 м в км | -0,001 км | -0,001 км | Пройден |

2)Негативное тестирование

| №    | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|------|---|---|---|---|
| N-01 | Пустая строка | Сообщение об ошибке | "Пожалуйста, введите корректное числовое значение!" | Пройден |
| N-02 | Ввод пробелов | Сообщение об ошибке | "Пожалуйста, введите корректное числовое значение!" | Пройден |
| N-03 | Ввод специальных символов (@#$) | Сообщение об ошибке | "Пожалуйста, введите корректное числовое значение!" | Пройден |
| N-04 | Ввод буквенной строки (abc) | Сообщение об ошибке | "Пожалуйста, введите корректное числовое значение!" | Пройден |
| N-05 | Ввод числа в неподдерживаемом формате | Сообщение об ошибке | "Пожалуйста, введите корректное числовое значение!" | Пройден |

Во всех негативных сценариях программа корректно обрабатывает ошибочный ввод и выводит сообщение об ошибке.

## 3. Описание обнаруженной ошибки

При конвертации температуры из градусов Цельсия в градусы Фаренгейта программа выдавала неверный результат.

- **Входное значение:** 0 °C.
- **Ожидаемый результат:** 32 °F.
- **Фактический результат:** -459,67 °F.
- **Причина:** некорректное определение единицы измерения температуры по её текстовой метке.

Ошибка была зарегистрирована в GitHub Issues и передана программисту для исправления.

## 4. Повторное тестирование после исправления

После внесения исправлений была выполнена повторная проверка температурных преобразований.

| № | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | 0 °C → °F | 32 °F | 32 °F | Пройден |
| 2 | 100 °C → °F | 212 °F | 212 °F | Пройден |
| 3 | 32 °F → °C | 0 °C | 0 °C | Пройден |
| 4 | 273,15 K → °C | 0 °C | 0 °C | Пройден |

## 5. Проверка пользовательских единиц измерения

Дополнительно была проверена возможность создания и использования пользовательской единицы измерения.

|  №   | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|------|---|---|---|---|
| C-01 | Создание и использование пользовательской единицы | Корректная конвертация | -1 м = -0,5 Тестовой единицы | Пройден |

## 6. Итог

В ходе тестирования проекта MCHPY были выполнены:
- 5 позитивных тестовых сценариев;
- 5 негативных тестовых сценариев;
- 4 регрессионных теста после исправления ошибки;
- 1 дополнительная проверка пользовательской единицы измерения.

В ходе первоначального тестирования была обнаружена ошибка конвертации температуры. Она была зарегистрирована в GitHub Issues, передана программисту и впоследствии исправлена.
После внесения исправления все четыре регрессионных теста завершились успешно.

Итог: все перечисленные тестовые сценарии пройдены успешно после устранения обнаруженной ошибки.
