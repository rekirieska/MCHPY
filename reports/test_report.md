# Отчёт о тестировании проекта MCHPY

## 1. Общая информация

**Проект:** MCHPY  
**Тип тестирования:** Ручное функциональное тестирование  
**Цель:** Проверка корректности работы конвертера величин, обработки пользовательского ввода и работы с пользовательскими единицами измерения.

## 2. Первоначальное тестирование

| № | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | Конвертация 1000 м в км | 1 км | 1 км | Пройден |
| 2 | Конвертация 0 °C в °F | 32 °F | -459,67 °F | Не пройден |
| 3 | Конвертация 1 USD в EUR | Корректное значение по курсу | 0,893269 EUR | Пройден |
| 4 | Конвертация 0 м в км | 0 км | 0 км | Пройден |
| 5 | Конвертация -1 м в км | -0,001 км | -0,001 км | Пройден |
| 6 | Ввод некорректного значения `abc` | Сообщение об ошибке без закрытия программы | Сообщение об ошибке, программа продолжает работу | Пройден |
| 7 | Создание и использование пользовательской единицы | Корректная конвертация | -1 м = -0,5 тестовой единицы | Пройден |

## 3. Описание обнаруженной ошибки

При конвертации температуры из градусов Цельсия в градусы Фаренгейта программа выдавала неверный результат.

- **Входное значение:** 0 °C.
- **Ожидаемый результат:** 32 °F.
- **Фактический результат:** -459,67 °F.
- **Причина:** некорректное определение единицы измерения температуры по её текстовой метке.

Ошибка была зарегистрирована в GitHub Issues и передана программисту для исправления.

## 4. Повторное тестирование после исправления

После внесения исправлений была выполнена повторная проверка температурных преобразований.

| № | Проверяемый сценарий | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | 0 °C → °F | 32 °F | 32 °F | Пройден |
| 2 | 100 °C → °F | 212 °F | 212 °F | Пройден |
| 3 | 32 °F → °C | 0 °C | 0 °C | Пройден |
| 4 | 273,15 K → °C | 0 °C | 0 °C | Пройден |

## 5. Итог

В ходе первоначального тестирования было проверено семь сценариев. В одном из них была обнаружена ошибка конвертации температуры.

После исправления программистом было проведено повторное тестирование четырёх температурных преобразований. Все повторные проверки завершились успешно.

**Итог:** обнаруженная ошибка исправлена, повторное тестирование пройдено успешно.
